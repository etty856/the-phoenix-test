# The Phoenix Home Assignment

This repository contains the solution for the Phoenix home assignment for backend developer open role.

## Project Structure
The repository is organized into two main parts:

1. **Exercise 1: S3 Json File Upload & Fetch** (`/s3-exercise-1`) - A Node.js application for interacting with AWS S3.
2. **Exercise 2: API Gateway & Lambda** (`/api-gateway-exercise-2`) - A serverless API for managing candidate data.

## Prerequisites
- AWS Account
- Node.js (v18 or higher)
- AWS CLI configured on your computer (for Exercise 1)

## Getting Started
To explore a specific exercise, navigate to its directory and follow the instructions in the local `README.md` file.
