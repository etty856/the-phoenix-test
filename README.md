# The Phoenix Insurance Company LTD
## Home Assignment

This repository contains my solution for the Phoenix Backend Developer home assignment.

## Project Structure

The repository is organized into two main parts:

1. **Exercise 1: S3 JSON File Upload & Fetch** (`/s3-exercise-1`)  
   A Node.js application for interacting with AWS S3.

2. **Exercise 2: API Gateway & Lambda** (`/api-gateway-exercise-2`)  
   A serverless REST API for managing candidate data.

## Prerequisites

- AWS Account  
- Node.js (v20.x or higher- Recommended) 
- AWS CLI configured locally (required for Exercise 1)

## Getting Started

To explore a specific exercise, navigate to its directory and follow the instructions in the local `README.md` file.
